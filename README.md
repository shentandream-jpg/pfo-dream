# PFO · 沈谭梦个人作品集

这是当前网站的可运行源文件与实际使用素材的整理版本。

## 目录

- `src/`：React 页面、项目数据和网站样式。
- `public/fonts/`：页面使用的斗鱼追光体与 Smiley Sans 字体。
- `public/images/`：网站品牌标识。
- `public/portfolio/`：项目卡片、详情图版与结束页使用的作品图片。
- 根目录：Vite、React 与 GitHub Pages 相关配置。

## 运行

```sh
pnpm install
pnpm dev
```

生产构建：

```sh
pnpm build
```

未包含 `node_modules`、构建产物、旧版样式、人像备份、示意封面图片和旧首页视频。
